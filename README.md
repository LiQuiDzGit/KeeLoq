Keeloq Remote  
for use with Flipper Zero  
-
All (65,535) key extracted   
-
Microchip HCS200/HCS300 KeeLoq Code Hopping Encoder based remotes.  
  
66 bits transmitted, LSB first.  
  
|  0-31 | Encrypted Portion  
| 32-59 | Serial Number  
| 60-63 | Button Status (S3, S0, S1, S2)  
|  64   | Battery Low  
|  65   | Fixed 1
